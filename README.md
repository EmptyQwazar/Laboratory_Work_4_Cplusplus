# Задание 1

## Задача 1

### Текст задачи

Реализовать определение класса `Time` (Вариант 1):
* **Поля:** часы (`hours_`) и минуты (`minutes_`).
* **Свойства:** геттеры и сеттеры для получения и изменения часов и минут с нормализацией в пределах суток (`00:00..23:59`).
* **Конструкторы (не менее трёх):** конструктор по умолчанию, конструктор с параметрами, конструктор копирования.
* **Вывод полей:** метод `getInfo()` для форматированного вывода времени в виде `ЧЧ:ММ`.
* **Метод согласно варианту:** добавление произвольного количества минут (`unsigned int`) к объекту типа `Time`. Результат должен быть типа `Time`.

Протестировать все методы, включая конструкторы; все исходные данные вводятся с клавиатуры с проверкой на корректность.

### Алгоритм решения

1. **Защита ввода (`readInt`):**
   * В бесконечном цикле `while (!(std::cin >> val))` считывается целое число. При некорректном вводе (буквы или символы) состояние потока сбрасывается через `std::cin.clear()`, буфер очищается через `std::cin.ignore(10000, '\n')`, и запрос повторяется.
2. **Нормализация времени (`Time::normalized`):**
   * Переданные часы и минуты переводятся в общее число минут суток: `total = hours * 60 + minutes`.
   * Берётся остаток от деления на количество минут в сутках (`1440`): `diff = total % 1440`. Если `diff < 0` (при переходе в предыдущие сутки), прибавляется `1440`.
   * Итоговые поля вычисляются как `hours_ = diff / 60` и `minutes_ = diff % 60`.
3. **Конструкторы и свойства:**
   * Конструктор по умолчанию `Time()` устанавливает время `00:00`.
   * Конструктор с параметрами `Time(int hours, int minutes)` вызывает `normalized(hours, minutes)`.
   * Конструктор копирования `Time(const Time& other)` копирует значения полей `hours_` и `minutes_`.
   * Геттеры `getHours()` и `getMinutes()` возвращают текущие значения полей; сеттеры `setHours(int)` и `setMinutes(int)` обновляют соответствующее поле с повторной нормализацией.
4. **Добавление минут (`Time::addMinutes`):**
   * Метод `addMinutes(unsigned int minutes) const` создаёт и возвращает новый объект `Time(hours_, minutes_ + static_cast<int>(minutes))`, не изменяя исходный объект.
5. **Форматированный вывод (`Time::getInfo`):**
   * Если `hours_ < 10` или `minutes_ < 10`, перед числом выводится ведущий ноль `'0'`, формируя вывод вида `ЧЧ:ММ`.
6. **Тестирование в `Task1()`:**
   * Создаётся объект конструктором по умолчанию, запрашиваются с клавиатуры часы и минуты, создаётся объект конструктором с параметрами и его копия конструктором копирования, затем считывается неотрицательное количество минут и проверяется работа `addMinutes()`.

# Задание 2

## Задача 1

### Текст задачи

Добавить к реализованному в первом задании классу `Time` перегруженные операции согласно Варианту 1:
* **Унарные операции:**
  * `++` — добавление минуты к объекту типа `Time` (префиксная и постфиксная формы);
  * `--` — вычитание минуты из объекта типа `Time` (префиксная и постфиксная формы).
* **Операции приведения типа:**
  * `short int` (явная) — результатом является количество часов (минуты отбрасываются);
  * `bool` (неявная) — результатом является `true`, если часы и минуты не равны нулю, и `false` в противном случае.
* **Бинарные операции:**
  * `+` (`Time t`, беззнаковое целое число `unsigned int` минут) — результатом является новый объект типа `Time`;
  * `-` (`Time t`, беззнаковое целое число `unsigned int` минут) — результатом является новый объект типа `Time`.

В главной функции `main` организовать дружественный интерфейс с меню для демонстрации всех функций.

### Алгоритм решения

1. **Унарные операторы инкремента и декремента:**
   * Префиксный `Time& operator++()` вызывает `normalized(hours_, minutes_ + 1)` и возвращает ссылку `*this`.
   * Постфиксный `Time operator++(int)` сохраняет копию текущего объекта `Time old(*this)`, выполняет `++(*this)` и возвращает старое значение `old`.
   * Аналогично реализованы префиксный `Time& operator--()` (уменьшает минуты на `1` через `normalized`) и постфиксный `Time operator--(int)`.
2. **Операторы приведения типа:**
   * `explicit operator short int() const` возвращает `static_cast<short int>(hours_)`, отбрасывая минуты.
   * `operator bool() const` возвращает `hours_ != 0 || minutes_ != 0` (`false` только для `00:00`).
3. **Бинарные операторы `+` и `-`:**
   * `Time operator+(unsigned int minutes) const` возвращает новый объект `Time(hours_, minutes_ + static_cast<int>(minutes))`.
   * `Time operator-(unsigned int minutes) const` возвращает новый объект `Time(hours_, minutes_ - static_cast<int>(minutes))` с автоматической нормализацией при переходе через полночь (`00:00 - 1 мин. = 23:59`).
4. **Проверка от исходного времени в `Task2()`:**
   * После ввода исходных часов `h` и минут `m` для каждого мутирующего оператора (`++t`, `t++`, `--t`, `t--`) создаётся отдельный экземпляр `Time(h, m)`, чтобы каждая операция демонстрировалась относительно исходного времени, а не накапливала изменения предыдущих шагов.
5. **Главное меню (`main.cpp`):**
   * В цикле `while (choice != 0)` через `switch (choice)` пользователь выбирает запуск `Task1()`, `Task2()` или выход из программы.
